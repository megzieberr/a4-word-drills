# A4 word drills (ENGV121)

Practice rounds for the ENGV121 A4 test: parts of speech and morphology, in Dr Annandale's labels,
plus three "Spot my errors" rounds in the test format.

Results stay in your own browser. Press **Copy my results** and paste them into your Claude chat
to get your why-sentences marked.

`index.html` is built from the source file by `build-lize-copy.py`; do not edit it by hand.
